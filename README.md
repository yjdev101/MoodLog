# MoodLog 🌙
감정을 기록하고 AI가 분석해주는 감정 일기 앱

## 배포 주소
http://13.211.116.18.nip.io:9090/

## 기술 스택
- Java 17, Spring Boot 3.5
- Spring Security + JWT, OAuth2 (Kakao/Google/Naver)
- Spring Data JPA, MySQL
- Docker / Docker Compose / AWS EC2
- Claude AI API (감정 분석)

## 주요 기능
- 감정 기록 및 캘린더 뷰 (감정별 색상 코딩)
- 월별 감정 통계
- AI 기반 감정 태그 분석
- 소셜 로그인 (카카오/구글/네이버)
